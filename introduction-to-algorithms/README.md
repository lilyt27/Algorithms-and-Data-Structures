# C Programming Notes

My study notes and worked examples from an introductory **Algorithms and Programming (C)** course.
Each topic has its own PDF with a short explanation of the concept, followed by complete example programs and their sample output.

## Topics

| # | Topic | What it covers |
|---|-------|----------------|
| 01 | [If-Else Statements](01_if_else.pdf) | `if`, `else if`, `else`, logical operators, nested conditions, leap year, triangle types, area calculations |
| 02 | [Switch-Case](02_switch_case.pdf) | `switch`, `case`, `break`, `default`, fall-through, calculator, grades, nested switch |
| 03 | [Loops](03_loops.pdf) | `while`, `do-while`, `for`, `break`, infinite loops, nested loops, overflow check |
| 04 | [Pointers](04_pointers.pdf) | addresses, `&` and `*`, pointer arithmetic, pointer to pointer, `void *`, pass by reference |
| 05 | [Arrays](05_arrays.pdf) | 1D arrays, `sizeof`, strings, random numbers, binary conversion, 2D arrays and matrices |
| 06 | [C Programming Fundamentals](06_C_Programming_Fundamentals.pdf) | Introduction to algorithms, flowcharts, data types, arithmetic/assignment/bitwise operators, type casting, and error types |
| 07 | [Memory Management Notes](07_Memory_Management_Notes.pdf) | Stack vs. Heap memory, dynamic memory allocation (`malloc`, `calloc`, `realloc`, `free`), memory leaks, and buffer overflows |

## Notes

- Every program was compiled with `gcc -Wall -Wextra` and run before its output was added to the PDFs.
- Memory addresses and random numbers will be different when you run the programs yourself.
